One word for make.fun's "One Word From Your Ex" bounty: the single word an ex would use to describe you. The program writes it (8 characters) to `/output/entry.txt`.

> practice

Why this word: an ex saying "he was practice" is the sharpest honest demotion — not an insult, but a rehearsal before the real thing. It lands instantly, needs no explanation, and no synonym keeps its edge.

## Run it

```sh
node main.ts
```
